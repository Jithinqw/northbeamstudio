## How the run the project

### Backend

Backend can be run by navigating to ```/backend ``` folder and running ```npm run dev```

### Frontend

Front end can be run by navigating to ```/frontend``` folder and running ```npm run dev``` 


## SDD Artifacts

SDD Archifacts reside in ```openspec``` folder.
